# MultivariateLab 公开课程网站

课程入口：https://thismely.github.io/multivariatelab-site/

本仓库只部署由教师审计的静态快照：知识页、原70项任务说明、清空输出Notebook及公开实验代码包。GitHub Pages公开访问，无账号门禁；仓库私有权限不能作为公开Pages网站的访问限制。

完整协作项目位于Gitee：https://gitee.com/hnist_eco_management/multivariatelab

本轮42个Gitee账号各自主责一项不同原任务；公开网站只提供账号、任务要求和操作教程，不发布学生姓名。学生在原Issue接单，完成个人交付与自检后，由教师另行指定非作者互审。

学生通知与Windows零基础操作指南提供在线阅读及PDF、Word下载。下载仅限教师确认的固定版本，构建和公开审计依据Gitee源项目的`project/student_handouts.json`校验文件哈希；不接受任意学生文档或已填写的私人材料。下载资料发布不代表学生已接单、已完成或已验收。

任务由教师派发，学生在Gitee提交、互审与维护，教师验收合并。Gitee包含教师确认可公开访问的119条冻结Tushare样本；本GitHub镜像不含真实样本、教师Token、执行结果、成绩或学生私人资料。

snapshot_manifest.json绑定Gitee源提交和每个静态文件的SHA256。工作流校验snapshot.zip后发布；Github仅承担网站发布，不建立第二套任务编号或分配流程。

更新时由教师从Gitee认可版本重建并导出新快照，上传snapshot.zip、snapshot_manifest.json和相应发布文件。禁止用push --mirror复制完整Gitee历史。
